# WINDY CITY BEEF RUN

A PS2-era open-city delivery driving game in the spirit of ALATURKA (bufuakgames), rebuilt for
Chicago — Italian beef runs past the Bean, the L and the green river.

- `index.html` — flat 3D version (keyboard + touch)
- `vr.html` — WebXR cockpit version for Meta Quest 3 (open in Quest Browser, tap ENTER VR)

Pure three.js (CDN importmap), no build step. Best score in localStorage.
